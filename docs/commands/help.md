## Usage and options

```text
usage: dps help [COMMAND]

Show the task-oriented command catalog or detailed help for one command.

Arguments:
  COMMAND               Command to explain. Omit it, or use "commands", to
                        show the complete command catalog.

Examples:
  dps help
  dps help commands
  dps help mdrun
  dps mdrun -h
```
